# iCastelo Dev - Programming and Technology Blog

A modern, responsive blog focused on programming, web development, and technology content. Built with pure HTML, CSS, and JavaScript, featuring a dark purple Y2K-inspired minimalist design.

## About

iCastelo Dev is an educational platform created to share knowledge about programming and technology. The site is optimized for Google AdSense approval and follows all best practices for content monetization.

## Features

-   Fully responsive design for all devices
-   Dark theme with purple Y2K minimalist aesthetic
-   Google AdSense integration ready
-   Ionicons icon library
-   Mobile-friendly navigation
-   Newsletter subscription form
-   Contact form
-   SEO optimized with meta tags

## Pages

-   **index.html** - Home page with featured articles
-   **sobre.html** - About page with author information
-   **contato.html** - Contact page with form
-   **privacidade.html** - Privacy Policy (LGPD compliant)
-   **termos.html** - Terms of Use

## Technologies

-   HTML5
-   CSS3 (Custom Properties, Flexbox, Grid)
-   JavaScript (ES6+)
-   Ionicons 7.1.0
-   Google AdSense

## Installation

1. Clone the repository:

```bash
git clone https://github.com/icastelito/home-icastelito.git
```

2. Open the project folder:

```bash
cd home-icastelito
```

3. Open `index.html` in your browser or use a local server.

## Usage

Simply open any HTML file in a web browser. For development, using a local server is recommended:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

## Google AdSense Setup

The site is pre-configured for Google AdSense:

1. The `ads.txt` file is already configured with the publisher ID
2. AdSense script is included in all HTML files
3. Required pages (Privacy Policy, Terms of Use, About, Contact) are included

## Customization

### Colors

Edit the CSS variables in `styles.css`:

```css
:root {
	--primary-color: #9333ea;
	--primary-dark: #7c3aed;
	--primary-light: #a855f7;
	--bg-dark: #0a0a0f;
	--bg-card: #13131a;
}
```

### Content

-   Update article content in `index.html`
-   Modify author information in `sobre.html`
-   Update contact email in `contato.html`
-   Customize privacy policy and terms as needed
